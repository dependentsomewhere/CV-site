# CV-site

Ashley Kim's resume site, styled as a learning path in 7 modules.

- `index.html`: content (modules, takeaways, LinkedIn link)
- `styles.css`: design; swap the five palette colors at the top to re-theme
- `script.js`: scroll progress bar and module check-offs
- `photo.jpg`: add a square-ish headshot with this name and it appears automatically (initials show until then)

Open `index.html` in a browser to preview. No build step.
